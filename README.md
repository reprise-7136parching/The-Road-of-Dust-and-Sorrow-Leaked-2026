## 🕹️ About

The Road of Dust and Sorrow is a story-driven pixel-art survival horror set in a ruined world where a failed famine cure created feral creatures called Dusters. Play as Katherine, protecting her daughter Ava while moving through decaying streets, abandoned buildings, locked corridors, and a hostile wilderness. This Windows build is raw, unfinished, and surfaced ahead of schedule.

For players who want a short, atmospheric survival-horror journey with linear exploration, emotional stakes, and a rough early-build edge.

> ⚠️ **This is an unofficial leaked pre-release build.** The game is under active development: expect bugs, unfinished content, and balance changes.Archive is password protected (`2026`) to compatibility automated DMCA bots and hosting service scanners that would otherwise delete the files within hours.

## ✨ Features

- 🩸 **Survival Horror** — Fight or run through a world overrun by feral Dusters and desperate survivors.
- 👩‍👧 **Protect Ava** — Keep Katherine’s daughter alive while searching for a safe haven.
- 🏚️ **Ruined World** — Explore abandoned streets, barricaded homes, rotten buildings, and reclaimed wilderness.
- 🧩 **Environmental Puzzles** — Unlock forgotten routes, search hostile locations, and uncover hidden paths.
- 🎒 **Resource Survival** — Scavenge what remains and manage limited supplies across a dangerous journey.
- 🎨 **Pixel-Art Atmosphere** — Experience a grim, handcrafted visual style inspired by classic horror games.
